# terminalwave

ターミナルの中だけで完結する、キーボード操作 (vim 風) の VCD 波形ビューアです。
GTKWave / vaporview のような波形確認を、SSH 先や GUI のない環境でもそのまま行えます。

- Rust 製のシングルバイナリ。Windows / Linux / macOS でネイティブに動作します (外部依存なし)
- 波形表示、拡大縮小、左右スクロール、信号の追加・削除・並べ替え、バスのビット展開
- 基数切替 (hex / dec / signed dec / bin / oct / ascii)、real / string 変数にも対応
- マーカー (`m{a-z}`) と Δ時間表示、変化点ジャンプ (`w` / `b`)、値検索 (`/`)
- 信号リストの保存と読み込み (`:w`)、VCD の再読み込み (`:e`)

## インストール

[Rust](https://rustup.rs/) (1.85 以降) が必要です。

```bash
cargo install --git https://github.com/shore6/terminalwave
```

ソースからビルドする場合:

```bash
git clone https://github.com/shore6/terminalwave
```

```bash
cd terminalwave && cargo build --release
```

`target/release/terminalwave` (Windows では `terminalwave.exe`) ができます。
`v*` タグを push すると GitHub Actions が Windows / Linux / macOS 向けのバイナリをリリースに添付します。

## 使い方

```bash
terminalwave dump.vcd
```

```
terminalwave [OPTIONS] <FILE.vcd>

  -s, --save <FILE>   :w で保存したレイアウト (信号リスト・マーカー) を読み込む
                      (省略時は VCD と同じ場所の <FILE>.twv があれば自動で読み込む)
  -l, --list          VCD 内の全信号を一覧表示して終了
  -h, --help          ヘルプ
  -V, --version       バージョン
```

レイアウトファイルがない状態で起動すると、左側に信号ツリーが開いた状態で始まります。
`j`/`k` で移動し、`Enter` で信号を追加して、`Tab` で波形に戻ってください。
サンプルは `examples/sample.vcd` にあります (`python3 examples/gen_sample.py` で再生成できます)。

## キー操作

アプリ内で `?` を押すと一覧が出ます。多くのコマンドは vim と同じように数字の前置で回数を指定できます (例: `10l`, `3k`, `5G`, `2dd`)。

### カーソル / スクロール

| キー | 動作 |
|---|---|
| `h` `l` / `←` `→` | カーソルを 1 列ぶん左右に移動 |
| `H` `L` | 半画面ぶん左右にスクロール |
| `Ctrl-b` `Ctrl-f` | 1 画面ぶん左右にスクロール |
| `w` / `b` | 選択中の信号の次 / 前の変化点へジャンプ (`e` は `w` と同じ) |
| `W` / `B` | 表示中のすべての信号を対象に、次 / 前の変化点へジャンプ |
| `0` `^` `Home` / `$` `End` | 先頭時刻 / 最終時刻へ |
| `zz` | カーソルを画面中央に |
| `:<time>` | 指定時刻へ移動 (`:1500`, `:1.5us`, `:30 ns`。単位なしは VCD の timescale 単位) |

### ズーム

| キー | 動作 |
|---|---|
| `k` `+` `=` | 拡大 (カーソル位置が中心) |
| `j` `-` `_` | 縮小 |
| `F` `zf` `:fit` | 全体表示 |
| `:zoom <t>` | 1 列あたりの時間を指定 (例: `:zoom 10ns`) |

### 信号リスト

| キー | 動作 |
|---|---|
| `J` `K` / `↓` `↑` | 選択する信号を移動 |
| `gg` / `G` | 先頭 / 末尾の信号を選択 (`5G` で 5 番目) |
| `Ctrl-d` `Ctrl-u` / `Ctrl-e` `Ctrl-y` | 半ページ / 1 行スクロール |
| `Alt-j` `Alt-k` | 選択中の信号を下 / 上へ移動 (並べ替え) |
| `dd` `x` | 削除 (レジスタに入る) |
| `yy` | ヤンク (コピー) |
| `p` `P` | レジスタの信号を下 / 上に貼り付け (`dd` → `p` で移動もできる) |
| `u` / `Ctrl-r` | アンドゥ / リドゥ |
| `r` | 基数を切り替え (hex → dec → sdec → bin → oct → ascii) |
| `:radix <r>` | 基数を指定 |
| `zo` `zc` `za` | バスを 1 ビットずつに展開 / 畳む / トグル |
| `<` `>` | 信号名欄の幅を変更 |

### 信号ツリー (信号の追加)

`a` `i` `o` `Tab` で信号ツリーにフォーカスします。`t` でツリーの表示・非表示を切り替えます。

| キー | 動作 |
|---|---|
| `j` `k` `gg` `G` `Ctrl-d` `Ctrl-u` | 移動 |
| `l` `→` | スコープを展開 / 信号を追加 |
| `h` `←` | スコープを畳む / 親スコープへ |
| `Enter` `Space` | 信号を追加 (スコープの上では開閉) |
| `a` | スコープ直下の信号をすべて追加 |
| `A` | スコープ以下の信号を再帰的にすべて追加 (フィルタ中は一覧にある信号をすべて追加) |
| `/` | インクリメンタル検索。スペースで区切ると AND 条件 |
| `Esc` `Tab` | 波形に戻る (フィルタがかかっていれば先に解除) |
| `q` `t` | ツリーを閉じる |

`:add <pattern>` で、フルパスに pattern を含む信号をまとめて追加することもできます (`:add *` ですべて)。

### マーカー / 検索

| キー | 動作 |
|---|---|
| `m{a-z}` | カーソル位置にマーカーを置く |
| `'{a-z}` `` `{a-z} `` | マーカーへジャンプ |
| `:marks` / `:delm!` | マーカー一覧 / 全削除 |
| `/<value>` | 選択中の信号がその値になる時刻を前方に検索 (表示中の基数で比較。`0x` や先頭の 0 は無視) |
| `n` `N` | 次 / 前を検索 |

最後に設定またはジャンプしたマーカーとカーソルとの時間差 (Δ) がヘッダに表示されます。

### ファイル / その他

| コマンド | 動作 |
|---|---|
| `:w [file]` | 信号リスト・基数・マーカー・表示範囲を保存 (省略時は `<vcd名>.twv`) |
| `:wq` | 保存して終了 |
| `:e` `R` | VCD を再読み込み (表示中の信号は維持。シミュレーションを回し直したとき用) |
| `:clear` | 信号リストを空にする |
| `:q` `q` | 終了 |
| `Ctrl-l` | 再描画 |
| `?` `:help` | ヘルプ |

## 表示の見方

- 1 ビット信号は High / Low の 2 段で描画します。`x` は赤い帯、`z` は黄色の中間線です
- バスは `╳` で値の切り替わりを示し、値の文字列を重ねて表示します。幅が足りない値は `…` で省略します
- 1 列の中で何度も変化している区間は、1 ビット信号では `│`、バスでは `▒` で表示します。拡大すると個々の変化が見えます
- 灰色の縦帯がカーソル、青い縦帯がマーカーです

Windows では Windows Terminal など、罫線文字と 256 色に対応したターミナルを推奨します。

## 対応している VCD

- `$timescale`、`$scope` / `$upscope`、`$var` (`[msb:lsb]` を別トークンで書く形式と名前に含める形式の両方)
- スカラー値 (`0` `1` `x` `z`。`h` / `l` / `u` / `w` / `-` などは 0 / 1 / x として扱う)、ベクター値 `b...` (左側の桁は規格どおり拡張)、`r...` (real)、`s...` (string)
- `$dumpvars` / `$dumpall` / `$dumpon` / `$dumpoff`、`$comment`
- 同じ ID を共有するエイリアス信号
